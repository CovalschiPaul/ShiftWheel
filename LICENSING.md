# Licensing status

No open-source license has been selected for ShiftWheel. Public repository visibility is not a grant of an open-source license. No LICENSE file is provided at this stage.

Third-party dependencies retain their own licenses. The build records resolved Python dependency versions in `build-dependencies.txt`; dependency ranges alone are not a complete license inventory. Review the applicable terms, including PyMuPDF and Qt, before redistributing a packaged build.

LibreOffice, FFmpeg and Tesseract executables are not included in the current installer. Any future bundle that includes them needs a corresponding redistribution review.

A project license and distribution policy remain explicit pre-stable-release decisions.
