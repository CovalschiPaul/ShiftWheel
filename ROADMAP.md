# Roadmap

These are proposed priorities, not release dates or promised features.

## Before a stable release

- [ ] Complete clean Windows install, startup, upgrade and uninstall acceptance checks.
- [ ] Verify Explorer drag/drop, Escape, high-DPI and multiple-monitor behavior.
- [ ] Test Office/OCR/media engines on clean Windows installations.
- [ ] Select a project license and document dependency redistribution obligations.
- [ ] Decide code signing and publish a durable, versioned release download.

## Everyday usability

- [ ] Job queue, clearer progress and safe cancellation.
- [ ] Searchable actions and favorites for frequently used conversions.
- [ ] Recent results with quick access to output folders.
- [ ] Clearer engine setup and supported-conversion discovery.

## Conversion quality

- [ ] Broader real-world fixture coverage using redistributable samples.
- [ ] Explicit multi-frame and multipage image controls.
- [ ] Better preview of Office export and spreadsheet pagination choices.

Suggest a concrete workflow in [Issues](https://github.com/CovalschiPaul/ShiftWheel/issues/new/choose). Include an example input/output pair and why the current flow is difficult.
