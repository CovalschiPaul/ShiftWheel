# Security

ShiftWheel is preview software. It processes files locally using several document and media libraries. Local processing is not a security sandbox; use files you trust and keep conversion engines updated.

Do not put credentials, private documents or unredacted logs in public issues. If GitHub shows **Security → Report a vulnerability**, use that private reporting route. Otherwise, open a minimal issue asking the maintainer for a private contact method, without exploit details or sensitive attachments.

There is no published security response SLA. Include the affected version, general impact and a synthetic reproducer through an agreed private channel.
